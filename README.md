A simple Paper plugin to automatically block Minecraft server scanners.

Made and tested in 26.1.2

The development process was documented [here](https://karak.al/blog/blocking-minecraft-server-scanners/)

# Usage
- Install like any other plugin
- Edit the config file
- Restart the server

# Requirements
- [PacketEvents](https://modrinth.com/plugin/packetevents)
- A domain for your server
